## 03. 🚀 FEATURED PROJECT: PRAHARI AI

> **AI Sentinel for Safer Roads** · Smart India Hackathon 2026 · Team *COMMAND + WIN*

India has some of the highest road-accident fatalities in the world, and ambulances are routed by *distance*, not *safety*. Road defects (potholes, broken streetlights, drainage) and accident risk are treated as separate problems. **PRAHARI connects them.**

<div align="center">
  <img src="./assets/prahari-flow.svg" width="100%" alt="PRAHARI pipeline: Detect, Predict, Respond"/>
</div>

| Stage | What it does | Tech |
|:--|:--|:--|
| 🔍 **Detect** | Citizens photograph a defect; a CNN classifies it (pothole / streetlight / garbage / drainage) and geotags it | PyTorch / TensorFlow, transfer learning |
| 📈 **Predict** | Scores accident risk per zone using history, weather, traffic and live defect density | scikit-learn, XGBoost |
| 🚑 **Respond** | Finds the fastest **and safest** ambulance path, not just the shortest | NetworkX, OSMnx, Dijkstra / A\* |

**Architecture:** React + Vite + Tailwind v4 + Leaflet dashboard → FastAPI backend → separate `ml-model` and `routing-engine` modules, with PostgreSQL/PostGIS for geo data.
